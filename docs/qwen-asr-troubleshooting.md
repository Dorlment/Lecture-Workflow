# Qwen 实时转写排错

先播放电脑上的课程声音，打开课堂工作台，检查「系统音频助手」正在捕获且音量有变化，再启动「实时转写」。文字连接测试不能验证语音识别。

## 超时提示分别代表什么

- **建立连接超时：**30 秒仍未完成 WebSocket 握手。检查网络、代理、Workspace ID 和北京地域配置。此时识别任务还没有启动。
- **启动任务超时：**连接已建立，但 `run-task` 发送完成后 30 秒仍未收到 `task-started`。检查实时转写模型与百炼服务状态。音频在任务启动前不会发送给 Qwen。
- **音频发送超时：**某块音频的本地发送回调超过 10 秒未完成。这不能证明 Qwen 已收到音频。检查网络、代理与报错时的发送缓冲；插件会停止本轮，避免无限积压。
- **控制指令发送超时：**启动或结束指令在本地等待发送完成超过 5 秒。它与等待服务端启动或结束确认不同。
- **Qwen 服务端超时：**服务通过 `task-failed` 报告超时。如果消息包含超时秒数，提示会显示这个数值。它与本地等待时间不同，增加文字服务的超时设置无法解决。
- **结束转写超时：**发送结束指令后，8 秒未收到结束确认。已写入笔记的定稿保留，但不能保证最后一段已完整返回。

停止转写时最多等待 11 秒排空音频发送队列，排空失败也会显示音频发送超时。复制的详情会列出实际的本地等待上限。

对于服务端超时，报错详情会记录最后收到助手音频帧和最后尝试发送音频的时间。如果很久没收到音频帧，检查是否暂停播放、切换了默认输出设备或助手停止出帧；收到音频帧仅说明助手有数据，不能证明数据已到达 Qwen。

## 其他错误

认证或权限错误：检查 API Key、Workspace ID、地域和模型权限是否属于同一套配置。HTTP 429 或 Throttling 表示限流，应检查并发与配额后重试；余额或额度错误需要在百炼控制台处理。HTTP 5xx 表示连接阶段的服务异常。DNS、连接重置和证书错误会分别显示已识别的网络错误码。

## 复制报错详情

`AllocationQuota.FreeTierOnly` 表示免费额度已耗尽或过期，且当前仅允许使用免费额度。百炼会在任务启动阶段拒绝请求，即使 WebSocket 已连接、系统音频正在捕获也不能转写。在百炼控制台补全付费信息，或关闭「仅使用免费额度」后才能继续付费调用；可能产生费用，插件不会自动调整计费设置。

如果启动后很快失败且显示「本轮未发送」，服务端是在接收音频前拒绝了任务，优先核对模型名称、访问权限和账户额度。在插件「高级设置：模型参数与自定义服务」中查看 `Realtime ASR Model`；「Qwen 视觉模型」是图片理解配置，不能用它判断实时转写模型。

`Free allocated quota exceeded` 表示免费额度到期或耗尽；`Arrearage` 或 `Access denied, please make sure your account is in good standing` 表示账户欠费；`PrepaidBillOverdue`、`PostpaidBillOverdue` 和 `BudgetLimitExceeded` 分别指账单或预算问题。`Throttling.AllocationQuota` 如果没有免费额度提示，通常是调用配额限流，不应直接判断为余额不足。`ModelNotFound` 也可能是模型名称、地域或未开通服务，并不能单独证明模型下线。参考[官方错误码](https://help.aliyun.com/zh/model-studio/error-code)。

在「实时转写 → 详细状态」点击「复制报错详情」。报告记录失败阶段、已识别的服务错误码、HTTP/网络状态、音频帧间隔、发送队列与缓冲，以及安全格式的任务 ID。截图或报错原文也可辅助排查。

报告不包含 API Key、Workspace ID、识别文字、音频或原始服务端响应。未识别的错误消息不会原样展示，也不会将猜测当作确定原因。需要阿里云进一步排查时，可提供任务 ID。

确认播放和配置正常后点击「重新启动实时转写」。失败期间的音频无法回补，因为插件不保存录音；已定稿并写入笔记的内容仍然保留。

协议参考：[阿里云实时语音识别服务端事件](https://help.aliyun.com/zh/model-studio/fun-asr-server-events)。
